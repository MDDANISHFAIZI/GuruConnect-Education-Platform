# GuruConnect – Hyperlocal Education Platform

GuruConnect is a full-stack education platform designed to connect students with nearby tutors while providing teachers with tools to manage students, attendance, fees, study materials, and classroom activities.

## Features

### Teacher Features

- Teacher Registration and Authentication
- Profile Management
- Student Management System
- Attendance Tracking
- Fee Management
- PDF Receipt Generation
- Notes and Homework Sharing
- Classroom Announcements
- Teacher Connection Code System

### Student Features

- Student Registration and Authentication
- Tutor Discovery by Locality
- Join Request System
- Teacher Code Enrollment
- Attendance Tracking
- Notes and Homework Access
- Fee Receipt Access
- Doubt and Announcement Access

### Platform Features

- Role-Based Authentication
- Hyperlocal Tutor Discovery
- Hindi and English Support
- Mobile Responsive Design
- Secure JWT Authentication
- Online and Offline Student Onboarding

## Technology Stack

### Additional Tools

## Project Architecture

The platform supports two user roles:

### Teacher

- Manage Students
- Track Attendance
- Manage Fees
- Upload Notes
- Share Homework
- Create Announcements

### Student

- Discover Tutors
- Send Join Requests
- Connect Through Teacher Codes
- Access Notes
- View Attendance
- Download Fee Receipts

## Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/guruconnect-education-platform.git
cd guruconnect-education-platform
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

## Environment Variables

Create a `.env` file inside the backend directory:

```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
PORT=5000
```
